# Suggested v3.1 Roadmap

1. Add optional EBU Tech 3341 loudness history and gated loudness detail.
2. Add cached metric fingerprints across separate application runs.
3. Add configurable mastering profiles for podcast, broadcast, audiobook, and
   high-dynamic-range music releases.
4. Add an optional desktop UI over the stable CLI and workflow engine.
5. Add signed standalone runtime builds with automated upstream license
   collection and vulnerability tracking.
6. Add multichannel and immersive-audio-specific phase and loudness handling.
7. Add report-to-report regression comparison for mix revision review.

v3.1 work should preserve the v3.0 CLI and report schema or introduce explicit
schema migration.
